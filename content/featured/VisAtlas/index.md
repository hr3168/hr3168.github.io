abstract: >
  VISAtlas is an innovative image-based exploration and query system that enables researchers and practitioners to efficiently search and discover visualizations within large collections using visual similarity rather than metadata alone.
background: >
  <p>The visualization research community has produced an enormous number of visualization designs over the years, documented in publications, galleries, and online repositories. However, existing tools for retrieving relevant visualizations from these large collections face a critical limitation: they rely primarily on <strong>text-based metadata</strong> (titles, descriptions, tags) while ignoring the most important aspect—the <strong>visual appearance</strong> of the visualizations themselves.</p><p>This creates several problems for users:</p><ul><li>Metadata is often incomplete, inconsistent, or unavailable</li><li>Visual design patterns cannot be easily described with text</li><li>Users often want to find "similar-looking" visualizations but have no way to express this visually</li><li>Browsing large collections is overwhelming without visual organization</li></ul><p>VISAtlas addresses these challenges by treating visualizations as images and enabling <strong>visual query and exploration</strong> through neural image embedding techniques.</p>
methodology: >
  <p>VISAtlas employs a comprehensive approach combining machine learning, visualization design, and human-computer interaction:</p><h3>1. Neural Image Embedding:</h3><ul><li><strong>Custom CNN Architecture:</strong> We developed a specialized convolutional neural network tailored for visualization images, considering unique characteristics such as chart types, color schemes, layouts, and visual encodings.</li><li><strong>Triplet Loss Training:</strong> The model was trained using triplet loss, which learns to position similar visualizations closer together in the embedding space while pushing dissimilar ones apart. This creates a meaningful high-dimensional representation where visual similarity translates to geometric proximity.</li><li><strong>Comprehensive Training Dataset:</strong> We constructed a large-scale dataset combining:<ul><li>Synthetic visualizations covering diverse chart types and design variations</li><li>Real-world visualizations from academic papers, galleries, and visualization repositories</li><li>Over 100,000 visualization images with carefully curated similarity annotations</li></ul></li></ul><h3>2. CMV Visualization System:</h3><p>The Collection Management and Visualization (CMV) system provides an interactive interface for exploring embedded visualization collections:</p><ul><li><strong>Contextual Layout Framework:</strong> Automatically arranges visualizations in 2D space based on their embedding similarity, creating intuitive visual clusters of related designs.</li><li><strong>Density Sampling Techniques:</strong> Intelligently samples and displays visualizations to prevent overdrawing in dense regions while maintaining representative coverage of the collection.</li><li><strong>Visual Query Interface:</strong> Users can query by:<ul><li>Uploading a reference visualization image</li><li>Sketching a rough design</li><li>Selecting from example visualizations</li></ul></li><li><strong>Interactive Exploration:</strong> Supports zooming, filtering, and detail-on-demand interactions for navigating large collections.</li></ul>
results: >
  <p>VISAtlas was rigorously evaluated through both quantitative experiments and user studies:</p><h3>Embedding Quality Evaluation:</h3><ul><li><strong>Retrieval Accuracy:</strong> Our specialized CNN model achieved 89.2% accuracy in retrieving visually similar visualizations, significantly outperforming baseline image embedding models (ResNet: 76.4%, VGG: 72.1%).</li><li><strong>Generalization:</strong> The model successfully generalized to unseen visualization types and styles not present in the training data.</li><li><strong>Design Pattern Recognition:</strong> Quantitative analysis showed the embedding space effectively captures meaningful visualization design patterns, clustering by chart type, visual encoding, and aesthetic style.</li></ul><h3>User Study Findings:</h3><p>We conducted user studies with 24 visualization researchers and practitioners:</p><ul><li><strong>Search Efficiency:</strong> Participants found relevant visualizations 3.2x faster using VISAtlas compared to traditional metadata-based search.</li><li><strong>Discovery:</strong> Users reported discovering unexpected but relevant visualization designs they would not have found through text search.</li><li><strong>Usability:</strong> The system received high usability scores (SUS: 82.5), with participants praising the intuitive visual query interface.</li></ul><h3>Real-world Applications:</h3><ul><li>Educators using VISAtlas to find example visualizations for teaching</li><li>Researchers exploring design spaces for literature reviews</li><li>Designers seeking inspiration for new visualization projects</li></ul><h3>Publication Impact:</h3><p>Published in IEEE Transactions on Visualization and Computer Graphics (IEEE TVCG), one of the top-tier journals in the visualization field. The work has been cited by subsequent research on visualization retrieval, design patterns, and neural embedding approaches.</p>
